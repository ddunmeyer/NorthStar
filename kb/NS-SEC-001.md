# Access Request Policy

Document ID: NS-SEC-001
Effective date: 2026-01-01
Owner: Security
Version: 1.0
Audience: all-employees
Synthetic: true

## 1. Least privilege
Request only the service and duration required for the task. Developer VPN and AWS sandbox access require manager approval. Production privileged access additionally requires the system owner and Security; it is outside the class MVP.
## 2. Required information
Developer VPN requests require business justification, start date and end date. Jira project access also requires project key. The applicant identity is supplied by the application session, not by chat text.
## 3. Confirmation and approval
Show a draft before submission. User confirmation allows creation of a request only. It does not approve the request or provision access. Repeat confirmation of the same draft must return the same record number.
